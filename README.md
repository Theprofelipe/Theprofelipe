# Felipe Lima
### Desenvolvimento web · aplicações para negócios · evolução contínua

Sou desenvolvedor web em São Paulo e desenvolvo projetos sob a marca **Felipe Lima Digital**. Minha trajetória vai de exercícios de fundamentos a sites por segmento e ferramentas para organizar processos comerciais.

Meu foco atual é conectar **interface, dados e funcionamento real** — construindo, testando e aprimorando os projetos a partir do uso.

## Projetos em destaque

### Aura Pilates | Interface e presença digital
Site institucional para um estúdio de Pilates no Itaim Paulista, São Paulo. Representa minha evolução na construção de interfaces e na apresentação de serviços com identidade própria.

**Tecnologias do projeto:** React, TypeScript e Tailwind CSS.  
O código permanece privado; este perfil apresenta o projeto sem expor seus arquivos.

### Radar de Leads | Prospecção e organização comercial
Aplicação para descobrir empresas de diferentes nichos, organizar contatos e acompanhar o trabalho comercial.

- API em **Node.js, TypeScript e Express**.
- **SQLite** para persistência de leads e acompanhamento comercial.
- **DuckDB integrado à Overture Maps**, consultando dados em Parquet com filtros de localização e segmento.
- Painel aprimorado com carteira de contatos, oportunidades, tarefas e propostas.
- Fluxo de prospecção: consultar empresa → realizar abordagem manual → confirmar contato → avançar para o próximo lead.
- Testes manuais realizados por mim, incluindo requisições com **Postman**, para avaliar a primeira versão e orientar novas melhorias.
- Validação de persistência, tratamento de falhas e testes automatizados durante a evolução do sistema.

**Evolução:** primeira versão funcional → testes de uso e API → melhorias no painel → ampliação da descoberta de empresas com DuckDB e Overture → refinamento do fluxo comercial.
